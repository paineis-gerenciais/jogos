# Marca de "Jogar e aprender"

Um dado em 3D feito só de linhas, com os nós em dourado, dentro de um quadrado azul-marinho.

Veja tudo junto em [`folha-da-marca.png`](folha-da-marca.png).

Segue o mesmo molde da marca dos Painéis Gerenciais, que fica no repositório `padroes`, pasta `marca/`.

## Arquivos

| Arquivo | Para quê |
|---|---|
| `assinatura-horizontal.svg` | Uso principal: símbolo e nome lado a lado, em fundo claro |
| `assinatura-horizontal-negativa.svg` | O mesmo, para fundo escuro |
| `assinatura-vertical.svg` | Símbolo em cima do nome, para espaço estreito ou quadrado |
| `assinatura-vertical-negativa.svg` | O mesmo, para fundo escuro |
| `simbolo.svg` | Só o símbolo, em fundo claro |
| `simbolo-negativo.svg` | Só o símbolo, em fundo escuro |
| `simbolo-uma-cor.svg` | Uma cor só, para carimbo e impressão em preto |
| `favicon.svg` | Ícone da aba do navegador (o mesmo da raiz do repositório) |
| `icone-app.svg` | Ícone de app, com fundo marfim e margem |
| `png/` | As mesmas peças em PNG: assinaturas (1200 e 800 px de largura), símbolo (512 px), ícones (512, 192, 180 e 32 px) |

Prefira o SVG: não perde qualidade em nenhum tamanho. Use o PNG onde o SVG não for aceito.

## Cores

| Cor | Código | Uso |
|---|---|---|
| Azul-marinho | `#23346b` | Cor principal |
| Grafite | `#24272e` | Textos e apoio |
| Dourado fosco | `#b0904f` | Só detalhe |
| Marfim | `#f6f3ee` | Fundos claros |

## Como usar

- Deixe em volta da marca um espaço livre igual a um quarto da largura do símbolo.
- Tamanho mínimo: símbolo com 16 px; assinatura horizontal com 120 px de largura.
- Em fundo claro, use a versão normal. Em fundo escuro, use a negativa.
- Não estique, não incline, não troque as cores e não ponha sombra ou brilho.

## Letra

O nome usa a letra Inter (licença livre, SIL Open Font License): Inter Display SemiBold em "JOGAR" e Inter Medium em "E APRENDER".
Nos arquivos, as letras já são desenho. Não é preciso instalar a fonte para usar a marca.
